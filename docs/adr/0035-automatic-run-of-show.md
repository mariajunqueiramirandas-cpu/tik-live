# ADR-0035: A run of show the host plans by itself

**Status:** Proposed
**Date:** 2026-10-18
**Deciders:** Project owner
**Amends:** ADR-0023 (where segments come from), ADR-0028 (what a loop is)

## Context

A creator builds the run of show (roteiro) by hand in the Roteiro tab:
titles, minutes, what to talk about, which minigame. Many creators just want
the host to run the whole show. The owner asked for a fully automatic
roteiro, turned on with a single switch.

## Decision

`persona.autoShow` (off when unset) switches the Roteiro tab to
**Roteiro 100% automático**. With it on:

- The director ignores the creator's segments and plays a run of show it
  plans itself (`autoShow` in `@tik-live/shared`): six segments, talk and
  minigames in turn, ending on a scored game so the loop closes on its
  podium and chat's vote on the last game (ADR-0029) still works.
- Talk segments are drawn from a fixed pool of formats (resenha, opinião
  polêmica, história do chat, perguntas, top 3, desafios…); games are drawn
  from every kind, without repeats in a loop. "Isso ou aquilo" never closes a
  loop: it has no winners.
- Every loop is planned again when the last segment ends, so a long stream
  doesn't repeat the same order. A seed drawn when the stream starts varies
  the plan between streams; segment ids carry the loop number.
- The plan doesn't depend on the persona, so edits mid-stream keep it.
  Switching the mode on or off mid-stream starts the new run of show from
  its first segment and drops an open vote.
- The creator's segments stay saved (the schema still requires one), and
  come back when the switch is turned off.
- The studio lists the run of show the director is actually playing
  (`RuntimeSnapshot.segments`, now with each segment's game), so the
  creator can still jump to a segment.

The pool is hand-written rather than generated by the model: no extra AI
calls or latency, nothing to moderate, and every prompt already follows the
safety rules (no politics, religion or real people).

## Consequences

- One switch gives a full show with no setup.
- Automatic segments are generic: they lean on the persona's own voice
  rather than a topic the creator chose. Creators who want themed segments
  keep the manual roteiro.
- Growing the pool is a code change.
